# PocketWise 💰

> A simple expense tracking web application designed to help students understand where their money goes.

## 📌 Problem

Students often receive a limited amount of pocket money each month, but small daily expenses such as food, travel, shopping, and entertainment can quickly add up.

By the end of the month, students may not know:

- Where their money was spent
- Which category consumed the most money
- How much money is still available
- Whether they are overspending

## 💡 Solution

**PocketWise** is a student-focused expense management web application that helps users track expenses, manage their monthly budget, and understand their spending habits.

The application provides a simple dashboard where users can:

- Set and monitor their budget
- Add and manage expenses
- Categorize spending
- View total spending
- Track remaining budget
- Analyze category-wise spending
- View recent transactions
- Get simple spending insights

## ✨ Features

### 📊 Dashboard
A central dashboard provides an overview of the user's financial activity.

### 💸 Expense Tracking
Users can record expenses with details such as:

- Amount
- Category
- Description
- Date

### 💰 Budget Management
Users can monitor:

- Monthly budget
- Total spent
- Remaining balance
- Budget progress

### 📈 Spending Analysis
PocketWise provides visual spending breakdowns to help users understand where their money is going.

### 💡 Smart Insights
The application analyzes spending patterns and provides simple insights and warnings to encourage better financial decisions.

### 🎯 Saving Goals
Users can set saving goals and track their progress.

### 🔐 User Interface
PocketWise includes a simple, responsive interface designed for students and everyday users.
