# PocketWise — User Flow

## 1. Overview

PocketWise is a student-focused expense tracking application that helps users record their daily expenses, monitor their monthly budget, and understand where their money is being spent.

The user flow is designed to be simple so that a student can record an expense within a few seconds and immediately see its effect on their budget.
