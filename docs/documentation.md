# PocketWise — Project Documentation

## 1. Project Overview

PocketWise is a student-focused expense tracking web application.

The application helps students manage their monthly pocket money by allowing them to record expenses, categorize spending, monitor their budget, and understand their spending habits through visual information and simple insights.

The project is designed as a lightweight web application with a simple and responsive user interface.

---

## 2. Problem Being Solved

Students often make multiple small purchases throughout the month.

Examples include:

- Food
- Transportation
- Shopping
- Entertainment
- Education
- Bills
- Other daily expenses

Because these expenses are usually small and frequent, students may not realize how much they have spent until their monthly pocket money is almost finished.

PocketWise solves this problem by bringing all expenses into one place and presenting the information in an easy-to-understand dashboard.

---

## 3. Main Features

### 3.1 Dashboard

The dashboard provides an overview of the user's financial activity.

It can display:

- Monthly budget
- Total amount spent
- Remaining budget
- Budget usage
- Spending breakdown
- Recent expenses
- Spending insights

---

### 3.2 Expense Tracking

Users can add their daily expenses.

Each expense can contain:

- Amount
- Category
- Description
- Date

The application uses this information to calculate the user's total spending.

---

### 3.3 Expense Categories

Expenses are organized into categories to make spending patterns easier to understand.

Current categories include:

- Food
- Travel
- Shopping
- Entertainment
- Education
- Bills
- Other

---

### 3.4 Spending Breakdown

PocketWise provides a visual breakdown of expenses by category.

The spending chart uses a donut-style visualization.

For each category, the application displays:

- Category name
- Amount spent
- Percentage of total spending

This allows users to quickly identify their highest-spending categories.
